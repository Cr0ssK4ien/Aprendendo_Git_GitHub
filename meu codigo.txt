-------- Branch ---------

git branch - mostra as branch
git branch "nome" - cria uma branch
git checkout "nome" - muda a branchs

-------- Unindo as Branch --------

1. git pull da branch principal
2. gerar uma nova branch da branch principal
3. trabalhar e adicionar novas funcionalidades na nova branch que criou
4. Finalizar o trabalho na branch temporária
5. Git checkout na branch principal
6. git pull
7. Mergiar(unir) o código da brancha temporáraio com a branch principal(depois de testar)
8. git push da branch principal
